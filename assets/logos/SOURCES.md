# Logo sources

- `github.svg`: unmodified `GitHub_Invertocat_Black.svg` from the [official GitHub logo package](https://brand.github.com/GitHub_Logos.zip), used beside the link to the owner's GitHub profile. [Brand reference](https://brand.github.com/foundations/logo).

The GitHub mark belongs to GitHub. The small line icons in `build.py` are geometric SVG UI symbols, not third-party logos. Decorative images and icons are hidden from assistive technology because their adjacent text supplies their meaning.
